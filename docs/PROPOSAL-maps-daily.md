## 1. ระบบธาตุ

### 1.1 ธาตุ 7 แบบ
| ธาตุ | ไอคอน | สี |
|---|---|---|
| ไฟ | 🔥 | ส้มแดง |
| น้ำ | 💧 | ฟ้า |
| ลม | 🌪️ | เขียวมิ้นต์ |
| ดิน | 🪨 | น้ำตาล |
| แสง | ✨ | ทอง |
| มืด | 🌑 | ม่วง |
| ไม่มีธาตุ | ⚪ | เทา |

### 1.2 แพ้ชนะ
```
วงล้อ:  ไฟ → ลม → ดิน → น้ำ → ไฟ      (ลูกศร = ชนะ)
คู่ปรับ: แสง ⇄ มืด                      (ชนะกันและกัน)
```
| ตีด้วยธาตุที่… | ตัวคูณดาเมจ | ตัวเลขที่เด้ง |
|---|---|---|
| ชนะธาตุเป้า | **×1.5** | สีเหลือง ตัวใหญ่ + "แรง!" |
| แพ้ธาตุเป้า | **×0.6** | สีเทา ตัวเล็ก + "ต้าน" |
| ธาตุเดียวกัน | ×0.75 | สีเทา |
| อื่น ๆ / ไม่มีธาตุ | ×1 | ปกติ |

- **มอนตีเรา:** ใช้ตารางเดียวกันกับ "ธาตุชุดเกราะ" ของเรา (ได้จากรูนตัวใหม่ เช่น รูนสไลม์น้ำ = เสื้อธาตุน้ำ)
  - ไม่มีรูนธาตุ = ไม่มีธาตุ = ×1 ทุกอย่าง
- **ป้ายบนหัวมอน:** ไอคอนธาตุเล็ก ๆ ข้างแถบเลือด
- **เมนูหยุดเกม:** มีตารางแพ้ชนะไว้ดู

### 1.3 ธาตุของสกิลที่มีอยู่ (ตามธีมเดิม)
| ธาตุ | สกิล |
|---|---|
| 🔥 ไฟ | หอกเพลิง · อุกกาบาตถล่ม · กับดักระเบิด · ศรระเบิด · ดวงไฟสุริยะ |
| 💧 น้ำ | วงแหวนน้ำแข็ง · พายุหิมะ |
| 🌪️ ลม | สายฟ้าลูกโซ่ · วังวนวายุ · พายุหมุนเหวี่ยง · ศรกระจาย · เหยี่ยวคู่ใจ |
| 🪨 ดิน | ทุบธรณี · หนามศิลา · ปราการเหล็ก |
| ✨ แสง | ลูกแสงศักดิ์สิทธิ์ · วงศักดิ์สิทธิ์ · กางเขนแห่งแสง · ลำแสงพิพากษา · หมัดศักดิ์สิทธิ์ · ดาบวิญญาณวน |
| 🌑 มืด | หมอกพิษ · เงาพริ้ว · ฟันเงาสังหาร · ร่างเงา · ศรสังหาร |
| ⚪ ไม่มีธาตุ | ฟันดาบ · หอกพุ่งทะยาน · ศรเวท · ยิงธนู · ห่าธนู · ศรวงแหวน · ปามีด · พัดใบมีด · ใบมีดหมุนวน · ระเบิดควัน |

- **สกิลที่ไม่ทำดาเมจ** (ออร่าผู้พิทักษ์ เลือดคลั่ง แสงฟื้นฟู เกราะเทวา) ไม่มีธาตุ
- **ศรเวทวิวัฒนาการ "ศรดวงดาว"** เปลี่ยนเป็นแสง: ให้ผลตอบแทนการวิวัฒนาการ
- **การ์ด/หน้าสกิลแสดงไอคอนธาตุ** ผู้เล่นจะได้รู้ว่าควรเอาสกิลไหนเข้า loadout ก่อนไปแผนที่ไหน (เช่น ไปบึงสไลม์ไฟ → เอาสกิลน้ำ)
- **คลาสสิกและเอาชีวิตรอด:** อันเดดเป็น "ไม่มีธาตุ" ทั้งหมด → ตัวคูณ = 1 → สมดุลเดิมและ golden ไม่เปลี่ยน
  - ทางเลือก: วันหลังให้อันเดดเป็นธาตุมืด (แสงแรง) ได้ แต่จะเปลี่ยนสมดุล ข้อเสนอนี้ยังไม่ทำ

## 6. ด่านรายวัน (เข้าจากป้อม → NPC "ผู้ดูแลหอทดสอบรายวัน")

ด่านรายวันใช้สนามแบบเอาชีวิตรอด (สร้างเร็ว ใช้โค้ดที่มีแล้ว) แต่สั้นและมีเป้าหมายเดียว
- **รีเซ็ต:** เที่ยงคืนตามเวลาเครื่อง
- **เลือกความยาก:**
  - 3 ระดับตามเลเวลตัวละคร: ง่าย / กลาง / ยาก
  - ยากกว่า = ตัวคูณรางวัลสูงกว่า (×1 / ×1.5 / ×2.2)
  - ยากต้องมีเลเวล ≥ ค่าที่กำหนด

| ด่าน | ครั้ง/วัน | เวลา | เป้าหมาย | รางวัล |
|---|---|---|---|---|
| **ลานวิญญาณประสบการณ์** | **2** | 3 นาที | ภูตแสงเรืองวิ่งหนีเป็นฝูง ไล่ตามฆ่าให้ได้มากที่สุด (ภูตตัวทองมีค่า ×5) | Base/Job EXP **×10** ของ EXP ที่ได้ในด่าน |
| **คลังทองก็อบลิน** | **2** | 3 นาที | ก็อบลินแบกถุงทองวิ่งรอบสนาม ตีให้ถุงแตก ทองกระจาย เก็บให้ทัน · มีหีบทองที่ต้องยืนเปิด 2 วิ | ทอง **×10** |
| **ห้องสมบัติหายาก** (เปลี่ยนตามวัน) | **1** | ~4 นาที | ฆ่ามอนครบ 3 คลื่น แล้วล้มผู้เฝ้าคลัง | หีบของหายากตามวัน |

ห้องสมบัติแต่ละวัน:
| วัน | ของในหีบ |
|---|---|
| จันทร์ | วัสดุตีบวก (แร่ / หินรูน) |
| อังคาร | เศษรูน + รูนธาตุ |
| พุธ | ยา + ผงรูน |
| พฤหัส | อุปกรณ์หายาก (ฟ้า/ม่วง) |
| ศุกร์ | หินตีบวกกันแตก (หายาก) |
| เสาร์ / อาทิตย์ | **สุ่มทุกแบบ + ครั้งที่ 2 ฟรี** |

- **ปุ่มด่วน:** หน้าหลักมีปุ่ม "📅 ด่านรายวัน" พร้อมป้ายจำนวนครั้งที่เหลือ เช่น "เหลือ 3"
- **ด่านล้มเหลว:**
  - ตายหรือหมดเวลาก่อนทำได้ = ได้รางวัลตามที่ทำได้
  - ไม่คืนสิทธิ์ (กันการกดซ้ำหาค่าสุ่ม)
- **การเซฟ:**
  - `acct.daily = {day:'2026-11-09', used:{exp:1, gold:0, rare:0}}`
  - สิทธิ์ถูกหักทันทีตอนกดเข้า (ในเซฟก่อนเริ่มด่าน) กันปิดแอปหนีแล้วได้สิทธิ์คืน
  - **แตะเงินและเซฟ → ต้องผ่าน tester ก่อน push**
- **ต่อกับหน้าอัปถาวรที่เสนอไว้:** ทองจากด่านทองเป็นแหล่งหลักของการอัปถาวร (EXP+, ระยะเก็บของ ฯลฯ)
