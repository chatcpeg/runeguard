## 0. สิ่งที่เจ้าของขอ (สรุป)
- การ์ดค่าสถานะในฉากต่อสู้ = การเพิ่ม **ความชำนาญ**
- DEX = ระยะโจมตี + ความเร็วโจมตี (+ เดิน) · STR สำหรับจอมเวท = HP / ความถึก / DEF เท่านั้น · INT สำหรับเวท = แรง + ขนาด + ลูกเล่น
- สกิลที่ปล่อยออกไป **เล็งครั้งเดียวตอนปล่อย แล้วตรงไปจนสุดระยะ** ไม่เลี้ยวตามมอน (ทุกอาชีพ)
- ลูกเล่นของสกิลลึก **30+ ระดับต่อสกิล** เช่น ลูกไฟโตขึ้น 5 ระดับ ระดับ 6 มีไอร้อนแผ่รอบ ฯลฯ
- Lv ของสกิลในรอบตันที่ ★ ที่ฝึกไว้ก่อนเข้าเท่านั้น (ตอนนี้ทำงานแบบนี้อยู่แล้ว · คงไว้)

**การตีความ "dex … ความเร็วในการโจมตี เดินมากกว่า"**: ผมอ่านว่า DEX เน้นความเร็วโจมตี/ระยะ **มากกว่า** ความเร็วเดิน (เดินได้นิดหน่อย) ส่วนความเร็วเดินเป็นงานหลักของ AGI — ถ้าตั้งใจให้ DEX เดินเร็วกว่า AGI บอกได้ ปรับตัวเลขในตารางข้อ 1 อย่างเดียว

## 1. การ์ดค่าสถานะ = ความชำนาญ (โหมดตัวละคร · คลาสสิกคงเดิม)

การ์ด 1 ใบให้ 2 ส่วน:
- **(ก) ผลทั่วไป** — ทุกอาชีพได้เหมือนกัน เล็ก ๆ ด้านการเอาตัวรอดและการควบคุม
- **(ข) ความชำนาญสกิล +1** — ทุกสกิลในรอบที่ใช้ค่านี้เป็น**ค่าหลัก**ได้ความชำนาญ +1 ระดับ (ข้อ 3) · ไม่มีเพดาน

| ค่า | (ก) ผลทั่วไปต่อใบ | (ข) สกิลที่ได้ความชำนาญ (ตัวอย่าง) |
|---|---|---|
| **STR** พละกำลัง | HP +2% · DEF +1 | สกิลกายภาพของนักดาบ/นักพรต: แรงขึ้น วงฟันกว้างขึ้น กระแทกแรงขึ้น + ลูกเล่น |
| **VIT** ความอึด | HP +4% · ฟื้น +0.25/วิ · DEF +0.5 | โล่ ทุบพื้น ฟื้นฟู: โล่หนาขึ้น ฟื้นมากขึ้น + ลูกเล่น |
| **AGI** ความว่องไว | เดิน +3% · หลบ +0.8% · โจมตีเร็ว +1% | สกิลเร็ว/หมุน (ใบดาบวน ศรกระจาย มีดพัด เงาพริ้ว…) |
| **DEX** ความแม่นยำ | **ความเร็วโจมตี +3% · ระยะโจมตี +4%** · เดิน +1% | สกิลยิง (หอก ธนู กางเขน ร่างเงา…) |
| **INT** สติปัญญา | พื้นที่ +2% · ระยะเวลา +2% | เวททุกชนิด: แรงขึ้น ใหญ่ขึ้น + ลูกเล่นหลากหลาย |
| **LUK** โชค | คริ +1.5% · แรงคริ +3% · ดูดของ +4% · ดรอป +1% | สกิลเสี่ยงโชค (มีดปา ศรสังหาร ห่าธนู…) |

- **จอมเวท** (ทุกสกิลใช้ INT): INT = แรง/ขนาด/ลูกเล่นของทุกเวท · DEX = ยิงไกลขึ้นและถี่ขึ้น · STR/VIT = ถึกขึ้นเท่านั้น (ไม่เพิ่มดาเมจ)
- **นักดาบ**: STR เป็นค่าดาเมจหลัก (ฟันดาบ หอกเพลิง… ตามตารางค่าหลักเดิม 40 สกิล) · VIT ไปที่โล่/ทุบ
- เพดานผลทั่วไป: เดิน +60% · หลบ 40% · ความเร็วโจมตี ×2.2 (คูลดาวน์ไม่ต่ำกว่า 45%) · ระยะ +80% · คริ 75%
- ต่างจากตอนนี้: STR ไม่เพิ่มดาเมจ "ทุกสกิล +12%" อีกแล้ว (นั่นทำให้จอมเวทเก็บ STR ได้คุ้ม) · การ์ดใบที่ 6+ ไม่ลดครึ่งอีกแล้ว (ใช้เพดานแทน)
- ชื่อบนการ์ดเปลี่ยนเป็น "ความชำนาญ INT Lv 7 → 8" และบอกว่าสกิลไหนได้ลูกเล่นใหม่ในใบนี้

## 2. การเล็งแบบใหม่ (ทุกอาชีพ · โหมดตัวละคร · คลาสสิกคงเดิม)

**กติกาเดียวกันทุกสกิล**: ตอนปล่อย เล็งไปที่ศัตรูที่ใกล้ที่สุด (หรือกลุ่มที่หนาที่สุดสำหรับสกิลวง) **ครั้งเดียว** แล้วสกิลวิ่งตรงจนสุดระยะ ไม่ตามมอน · ระยะ = ค่าของสกิล × DEX

| แบบ | สกิล | ตอนนี้ | ใหม่ |
|---|---|---|---|
| ลูกกระสุน | ศรเวท · ลูกแสงศักดิ์สิทธิ์ | เลี้ยวตามเป้า | **ตรงจนสุดระยะ** ไม่เลี้ยว (ชดเชย: ทะลุ +1 · ลูกใหญ่ขึ้น) |
| ลูกกระสุน | หอกเพลิง หอกพุ่ง ยิงธนู ศรกระจาย ศรระเบิด มีดปา พัดใบมีด ศรวงแหวน ศรสังหาร | ตรง แต่หมดอายุก่อนถึงขอบระยะบ้าง | ตรงจนสุดระยะ (ระยะคงที่ต่อสกิล + DEX) |
| ตกจากฟ้า | อุกกาบาต ห่าธนู กางเขน ลำแสงพิพากษา | ตกที่ศัตรู**สุ่ม**ในจอ | ตกที่จุดเล็ง · ลูกถัดไปเรียงเป็นแนวต่อจากจุดแรก (อ่านง่าย หลบ/วางแผนได้) |
| วงบนพื้น | พายุหิมะ หมอกพิษ | วางที่ศัตรูสุ่ม | วางที่จุดเล็ง |
| วงเคลื่อนที่ | วังวนวายุ | ไล่ตามศัตรู | **พุ่งตรงไปทางที่เล็ง** แล้วค่อย ๆ ช้าลง (ดูดระหว่างทาง) |
| วางกับดัก | กับดักระเบิด | วางสุ่มรอบตัว | วางใต้เท้าตอนเดินผ่าน (เป็นแนวตามทางที่เดิน) |
| ชิ่ง | สายฟ้าลูกโซ่ | ตัวแรกใกล้สุด | คงเดิม (การชิ่งคือธรรมชาติของสกิล) · ตัวแรกต้องอยู่ในทิศที่เล็ง ±30° |
| ฟันวง | ฟันดาบ หมัด ใบมีดหมุน พายุหมุน | ทิศศัตรูใกล้สุด | คงเดิม · ระยะฟันได้จาก DEX/STR |
| เรียกสัตว์ | เหยี่ยว ร่างเงา | เหยี่ยวไล่เป้า · ร่างเงาเล็ง | เหยี่ยวโฉบเป็นเส้นตรงผ่านจุดเล็ง · ร่างเงาเล็งครั้งเดียวต่อนัด (มีดตรง) |
| รอบตัว/ติดตัว | ดาบวิญญาณวน ดวงไฟ ออร่า โล่ ฟื้นฟู เลือดคลั่ง เงาพริ้ว ระเบิดควัน ทุบธรณี วงแหวนน้ำแข็ง | — | ไม่ต้องเล็ง (คงเดิม) |
| พุ่งฟัน | ฟันเงาสังหาร | ตัว HP มากสุด | คงเดิม |

- วิวัฒนาการ "ศรดวงดาว" (เดิมติดตาม 6 ลูก) → **พัดดาว 6 ลูกตรง ทะลุ 3**
- ทางเลือกเสริมทีหลัง: ตั้งค่า "เล็งตามทิศที่เดิน" สำหรับคนที่อยากเล็งเอง

## 3. ความชำนาญสกิล 35 ระดับ (+ ไม่มีเพดานหลังจากนั้น)

**โครงเดียวกันทุกสกิล** (ตัวเลขต่อสกิลปรับได้):
- ทุกระดับ: แรง +4% (ระดับ 35 = +140%) · บางสกิลขนาด/รัศมี +2%
- **Lv 1–5**: รูปร่างโตขึ้นทีละขั้น (เห็นได้ชัดบนจอ)
- **Lv 6, 10, 12, 15, 18, 20, 22, 25, 28, 30, 32**: ลูกเล่นใหม่ (ภาพ + ผล) 11 อย่าง
- **Lv 35**: ร่างสุดท้ายของสกิล
- **Lv 36+**: แรง +1%/ระดับ ไปเรื่อย ๆ (ไม่มีภาพใหม่)
- ความชำนาญเป็นของในรอบนั้น (เริ่ม 0 ทุกรอบ) · อัปเกรดถาวร 🧬 "พลังผูกค่าสถานะ" เปลี่ยนเป็น "เริ่มรอบด้วยความชำนาญ +n"

### 3.1 ตัวอย่างเต็ม: 🔥 หอกเพลิง (ลูกไฟจอมเวท)
| ระดับ | ภาพ | ผล |
|---|---|---|
| 1–5 | ลูกไฟกลมเล็ก → โตขึ้นทีละขั้น หางไฟยาวขึ้น | ขนาด +8%/ขั้น |
| **6** | **ไอร้อนแผ่เป็นวงสั่นไหวรอบลูกไฟ** | ศัตรูที่ลูกไฟเฉียดในวง 2.5 ม. โดนลวก 10% |
| 7–9 | ไอร้อนกว้างขึ้น ลูกไฟใหญ่ขึ้น | วงลวก +10%/ขั้น |
| **10** | เปลวไฟหยดลงพื้นตามทาง | ทางไฟ 1.5 วิ |
| **12** | ระเบิดมีสะเก็ดไฟกระเด็น 3 ชิ้น | สะเก็ด 25% |
| **15** | แกนลูกไฟเป็นสีขาว (ร้อนจัด) | ทะลุ 1 ตัวก่อนระเบิด |
| **18** | ระเบิดสองระลอก | ระลอกสอง 50% |
| **20** | **ไฟสีน้ำเงิน** ทั้งลูก | แรง +25% · ติดไฟ 3 วิ |
| **22** | อากาศรอบลูกไฟบิดเบี้ยว | ศัตรูในวงไอร้อนช้าลง 15% |
| **25** | ถึงสุดระยะแล้วแตกเป็น 3 ลูก | ลูกเล็ก 40% |
| **28** | ทางไฟลามเป็นเส้นยาว | ทางไฟ 3 วิ แรงขึ้น |
| **30** | ระเบิดเป็นวงแหวนสุริยะ | ระเบิด ×1.5 และดูดศัตรูเข้ากลาง |
| **32** | ลูกไฟสองลูกหมุนพันเป็นเกลียว | ยิงเป็นคู่ |
| **35** | **ร่างสุดท้าย "หงส์เพลิง"** นกไฟกางปีก | ทะลุทุกตัวตลอดทาง ทิ้งทางไฟ แล้วระเบิดใหญ่ที่ปลายทาง |

### 3.2 จอมเวทอีก 7 สกิล (ลูกเล่นหลัก ระดับ 6 / 15 / 20 / 25 / 35)
| สกิล | 6 | 15 | 20 | 25 | 35 ร่างสุดท้าย |
|---|---|---|---|---|---|
| 🔹 ศรเวท | ประกายเวทวนรอบลูก | ทะลุ +1 | ลูกแยก 2 ตอนชน | พัด 5 ทิศ | ศรรุ้งเจ็ดสี ทะลุทุกตัว |
| ❄️ วงแหวนน้ำแข็ง | เกล็ดน้ำแข็งลอยรอบตัว | แช่แข็ง 0.5 วิ | วงที่สองตามมา | ตัวแข็งแตกเป็นเศษ | ยุคน้ำแข็ง: พื้นน้ำแข็งถาวร 5 วิ |
| ⚡ สายฟ้าลูกโซ่ | สายฟ้าสองเส้นพันกัน | ชิ่ง +2 | ชิ่งแตกสาย | สตันทุกตัวที่โดน | สายฟ้าเทพ: ฟ้าผ่าลงทุกจุดที่ชิ่ง |
| ☄️ อุกกาบาต | หางไฟลากยาว | ลูกเพิ่ม +1 | หลุมลาวา | อุกกาบาตกระดอน | ดาวหางยักษ์ข้ามจอ |
| 🌨️ พายุหิมะ | เกล็ดหิมะใหญ่ขึ้น | ลูกเห็บตก | พายุเคลื่อนตามแนวเล็ง | แช่แข็งตัวที่อยู่ครบ 2 วิ | พายุหิมะทั้งจอ 3 วิ |
| 🌬️ วังวนวายุ | ใบไม้หมุนในวังวน | ดูดแรงขึ้น | ใบมีดลมกระเด็น | วังวนแยกสองลูก | ทอร์นาโดยักษ์กวาดเป็นเส้น |
| 🪨 หนามศิลา | ฝุ่นหินพุ่ง | หนามสองแถว | หนามระเบิดหิน | กำแพงหินกั้น | ภูเขาหนามผุดเป็นวง |

### 3.3 อาชีพอื่น (โครงเดียวกัน · ร่างละเอียดตอนลงมือทีละอาชีพ)
| อาชีพ | ค่าที่ขับความชำนาญ | ตัวอย่างร่างสุดท้าย |
|---|---|---|
| นักดาบ | STR (ฟัน/หอก/พายุ) · VIT (โล่/ทุบ/ออร่า) · AGI (ดาบวน) | ฟันดาบ → "คลื่นดาบพระจันทร์" · ทุบธรณี → "แผ่นดินแยกเป็นเส้น" |
| นักธนู | DEX (ยิง) · AGI (กระจาย/เหยี่ยว) · LUK (ห่า/สังหาร) · INT (กับดัก) | ยิงธนู → "ศรดาวตก" · เหยี่ยว → "ฝูงเหยี่ยวพายุ" |
| นักบวช | INT (แสง/พิพากษา) · VIT (ฟื้นฟู/โล่) · STR (หมัด) · DEX (กางเขน) | ลำแสงพิพากษา → "เสาแสงสวรรค์ 12 ต้น" |
| โจร | AGI (พัด/เงา/หมุน) · LUK (มีด/ฟันเงา) · DEX (ร่างเงา) · INT (พิษ) | มีดปา → "พายุมีดจันทร์ดับ" |

## 4. ผลกับระบบเดิม
- **แทนที่**: "ค่าหลัก +0.5%/ใบ" + "จุดเปลี่ยนทุก 5 ใบ" (26-stat-scaling) → ความชำนาญ 35 ระดับ
- **คงไว้**: ต้นไม้สกิล (เลือกทางถาวร) · ★ / ขั้นสอง ★6–8 (เพดาน Lv สกิล) · วิวัฒนาการ · ระดับเริ่มต้นที่ซื้อด้วยรูน
- **คลาสสิก**: ค่าสถานะแบบเดิม การเล็งแบบเดิม (golden ไม่เปลี่ยน)
- **การ์ดในรอบ**: สกิลขึ้นได้ถึง ★ แล้วหยุด · หลังจากนั้นเป็นการ์ดความชำนาญล้วน (มีลูกเล่นใหม่ให้รอทุกไม่กี่ใบ)
