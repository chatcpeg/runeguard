## 2. ต้นไม้สกิล (ใหม่) — หน้าต่าง flow chart ต่อสกิล

### 2.1 รูปร่างต้นไม้ (ทุกสกิลใช้แบบเดียวกัน)

```
                 ┌──────────── ลำต้น ★1…★5 (เดิม) ── ★6…★8 ขั้นสอง (หลังเปลี่ยนอาชีพ) ────────────┐
                 │                                                                                │
   สาย A (เช่น พลัง)          สาย B (เช่น ชิ่ง)            สาย C (เช่น แยกสาย)
   A1 ตัวเลข ×3 ขั้น           B1 ตัวเลข ×3 ขั้น            C1 ตัวเลข ×2–3 ขั้น
      │ ต้อง ★2                   │ ต้อง ★2                    │ ต้อง ★2
   A2 ตัวเลข/ผลรอง ×2 ขั้น       B2 ×2 ขั้น                    C2 ×2 ขั้น
      │ ต้อง ★4                   │ ต้อง ★4 + A1≥2 (ข้ามสาย)    │ ต้อง ★4
   A3 ★ความพิเศษ (1 ขั้น)       B3 ★ความพิเศษ                 C3 ★ความพิเศษ
                 └──────────────┬──────────────┘
                     มงกุฎ (1 ขั้น) ต้อง: อาชีพขั้นสูง + มี ★ความพิเศษ 2 ใน 3
```

- **ทุกสกิล = 3 สาย × 3 ชั้น + มงกุฎ 1 = 10 โหนด** (รวมขั้นได้ ~19 ขั้นต่อสกิล)
- **ชั้น 1–2 = ตัวเลข** (ดาเมจ %, จำนวนชิ่ง, จำนวนเส้น, รัศมี, คูลดาวน์ ฯลฯ)
- **ชั้น 3 = ความพิเศษ** ที่เปลี่ยนวิธีทำงานของสกิล (ระเบิด, ชิ่งของชิ่ง, แช่แข็ง, ทิ้งพื้นไฟ …)
- **เงื่อนไขข้ามสาย** (require) ใส่เฉพาะที่สมเหตุสมผล เช่น "ชิ่งของชิ่ง ต้องพลังโจมตี A1 ขั้น 2" ตามที่เจ้าของยกตัวอย่าง
- **มงกุฎ** เปิดได้หลังเลื่อนอาชีพเท่านั้น — เป็นเหตุผลให้กลับมาเล่นสกิลขั้นต้นต่อหลังเปลี่ยนอาชีพ

### 2.2 แต้มที่ใช้ — **แต้มรูน (ใหม่)** แยกจากแต้มสกิลเดิม

- แต้มสกิลเดิม (จาก Job Lv, รวม ~45) ยังใช้ซื้อ ★ ลำต้นกับ passive เหมือนเดิม — ไม่ต้องเปลี่ยนเซฟเดิม
- **แต้มรูน** ได้ 1 แต้มต่อ Base Lv (สูงสุด 60) + ด่านรายวัน "ห้องของหายาก" ให้เพิ่ม (เฟส A)
- ต้นทุน: ชั้น 1 = 1 แต้ม/ขั้น · ชั้น 2 = 2 แต้ม/ขั้น · ชั้น 3 = 4 แต้ม · มงกุฎ = 6 แต้ม → ต้นไม้เต็ม 1 ต้น ≈ 38 แต้ม
  → ตัวละครเต็ม 60 Lv ทำเต็มได้ ~1.5 ต้น ต้อง **เลือก** ว่าจะลงลึกสกิลไหน (นี่คือ "หลายมุม" ที่เจ้าของอยากได้)
- รีเซ็ตต้นไม้: ใช้กติกาเดียวกับรีเซ็ตสกิล (ฟรีก่อน Lv 20 · ฟรี 1 ครั้ง · ม้วนลืมเลือน) แยกต่อต้น

### 2.3 ผลในรอบ

- โหนดตัวเลขเข้าทางเดียวกับค่าหลัก (`s.mod` ใน `pv()`) — ไม่ต้องแก้ behaviour ทุกตัว
- ความพิเศษชั้น 3/มงกุฎ = ธงบนสกิล (`s.tree.flags`) ที่ behaviour อ่าน เช่น `BEH.chain` อ่าน `fork` (ชิ่งของชิ่ง)
- การ์ดในรอบยังเหมือนเดิม (Lv1–5, วิวัฒนาการ) — ต้นไม้เป็น "ของติดตัวถาวร" ที่ทำงานตั้งแต่ Lv1
- โหมดคลาสสิก (ไม่มีตัวละคร) ไม่มีต้นไม้ → golden test ไม่เปลี่ยน

- การ์ดเลเวลอัปในฉากต่อสู้: ปุ่ม ? มุมบน = อธิบายชนิดการ์ด, 5 ใบ, สุ่มใหม่, แพคสนับสนุน
  และปุ่ม ? มุมขวาล่างของ**ทุกการ์ด** = ตัวเลขเต็มของใบนั้น (ค่าก่อน/หลัง · ผลรวมจากต้นไม้และค่าสถานะ · เพดาน ★ · ทางวิวัฒนาการ · จุดเปลี่ยนค่าสถานะ)

- ใช้ข้อความที่สร้างจากตัวเลขจริงในโค้ด (เหมือนบรรทัดตัวเลขบนการ์ดตอนนี้) ไม่ใช่ข้อความเขียนมือ → ตัวเลขตรงเสมอเมื่อปรับสมดุล
- หน้าอื่นที่ควรมี ? ด้วยในรอบเดียวกัน: หน้าสกิลของตัวละคร · หน้าอัปเกรดถาวร · หน้าพักเกม

## 4. ศรเวทแรงเกิน + ขั้นสองตอนเปลี่ยนอาชีพ

ต้นเหตุ: ศรเวท Lv5 = 3 ลูก + DEX ได้กระสุนเพิ่ม + ค่าหลัก → ยิง 5–6 ลูกติดตามเป้าทุก 0.42 วิ ตั้งแต่ต้นเกม

ข้อเสนอ (เฉพาะโหมดตัวละคร · โหมดคลาสสิกคงเดิม):
- **ขั้นต้น ★1–★5 ทอนลง**: สกิลแรกของทุกอาชีพ จำนวนลูกสูงสุด 2 (เดิม 3) · ดาเมจ Lv5 ลด ~15%
- **ขั้นสอง ★6–★8** เปิดเมื่อเลื่อนอาชีพแล้ว (ใช้แต้มสกิลขั้นสูง ขั้นละ 2) → ในรอบอัปได้ถึง Lv6–Lv8
  เช่น ศรเวท Lv6 = 3 ลูก, Lv7 = ทะลุ +1, Lv8 = 4 ลูก — แรงกว่าเดิมแต่ต้องเปลี่ยนอาชีพก่อน
- ใช้กับสกิลขั้นต้นทั้ง 6 สกิลของทุกอาชีพ (ไม่ใช่แค่ศรเวท)
- วิวัฒนาการยังเป็นที่ Lv5 เหมือนเดิม
