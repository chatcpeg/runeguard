# ข้อเสนอ: ค่าสถานะในรอบแบบไม่มีเพดาน + ผลต่อสกิลรายอาชีพ (ร่าง 2026-11-09 · รอเจ้าของเลือก)

## สิ่งที่เจ้าของขอ

- **การ์ดค่าสถานะไม่มีวันหมด:** การ์ด ATK / AGI / VIT / INT / DEX / LUK ตอนเลเวลอัพต้องสุ่มมาได้ตลอด ส่วนการ์ดสกิลยังหมดได้ตามเลเวลที่อัปไปแล้ว
- **ค่าสถานะต้องเปลี่ยนสกิลเสมอ:**
  - ทั้งรูปร่าง และความแรงของสกิล
  - ตัวอย่าง: จอมเวทอัป INT แล้ว เวททั้งใหญ่ขึ้นและแรงขึ้น
- **ความแรงเพิ่มเริ่มที่ 0.1% ต่อแต้ม:** หน้าอัปเกรดถาวรอัปอัตรานี้ให้สูงขึ้นได้

## 0. ภาพรวม

| | ตอนนี้ | ข้อเสนอ |
|---|---|---|
| เพดานการ์ดค่าสถานะ | 5 ใบต่อค่า | **ไม่มีเพดาน** (เฉพาะโหมดที่ใช้ตัวละคร) |
| ผลทั่วไปของค่าสถานะ | ใบที่ 1–5 ตามตารางเดิม | ใบที่ 1–5 เหมือนเดิมทุกตัวเลข · ใบที่ 6 ขึ้นไปได้ "ส่วนเกิน" ครึ่งหนึ่งของเดิม มีเพดานกันเกม |
| ความแรงตามค่าสถานะ | ATK ตัวเดียว | **ทุกสกิลมี "ค่าหลัก"** เช่น สายฟ้า = DEX ทุกแต้มของค่าหลักเพิ่มดาเมจสกิลนั้น **0.1%** (อัปถาวรได้ถึง 1.1%) |
| รูปร่างสกิล | INT = ใหญ่ขึ้น · DEX = +1 ลูกที่ใบ 3/5 | ทุกสกิลมี **จุดเปลี่ยนทุก 5 แต้ม** ของค่าที่ผูกไว้ เช่น สายฟ้า DEX 5/10/15 → +1 สายทุกครั้ง |

- **โหมดคลาสสิกไม่เปลี่ยน:** ยังเป็นเกมเดิม (เพดาน 5 · ไม่มีค่าหลัก) ผลทดสอบ golden จึงเหมือนเดิม
- **เลเวลกับการวิวัฒนาการไม่เปลี่ยน:** ยังใช้ "สกิล Lv5 + ค่าที่ผูก ≥ 1" เหมือนเดิม

## 2. ค่าหลักของสกิล (ความแรง) + จุดเปลี่ยนทุก 5 แต้ม

### กติกา
- **ความแรงตามค่าหลัก:** ดาเมจสกิล × (1 + **r** × แต้มของค่าหลัก)
  - **r = 0.1% ต่อแต้ม** ตามที่เจ้าของกำหนด
  - หน้าอัปเกรดถาวรมีหัวข้อใหม่ "พลังผูกค่าสถานะ" +0.1% ต่อขั้น 10 ขั้น → สูงสุด **1.1% ต่อแต้ม**
  - **ข้อสังเกต:** ที่ 0.1% เก็บ INT 20 ใบได้แค่ +2% ผู้เล่นแทบไม่รู้สึกจนกว่าจะอัปถาวร ถ้าอยากให้รู้สึกตั้งแต่แรก ผมแนะนำเริ่ม 0.5%
- **"แต้ม" ของค่าหลัก** = การ์ดในรอบ + (โหมดตัวละคร) ค่าสถานะถาวรของตัวละคร ÷ 5
  - เหตุผล: ตัวละครที่ลง INT ถาวรมาเยอะ ควรได้ประโยชน์ด้วย แต่ไม่ให้ทับการ์ดในรอบ
- **จุดเปลี่ยน:** ทุกครั้งที่ค่าที่ผูกไว้ครบ 5 / 10 / 15 … สกิลได้ความสามารถเพิ่มตามตาราง
  - จุดเปลี่ยนเอาแต้มจากการ์ดในรอบเท่านั้น
  - **การ์ดค่าสถานะบอกล่วงหน้า** เช่น "INT 4 → 5: สายฟ้า +1 ครั้งกระโดด"

## 4. การแสดงผล

- **การ์ดค่าสถานะ:** บอกสามอย่าง
  1. ผลทั่วไปก่อน→หลัง (มีแล้ว)
  2. ความแรงที่เพิ่มของสกิลที่ใช้ค่านี้เป็นค่าหลัก เช่น "สายฟ้าลูกโซ่ ดาเมจ +0.1%"
  3. **จุดเปลี่ยนที่ใกล้ถึง** เช่น "อีก 1 ใบ: สายฟ้า +1 สาย"
- **หน้าพักเกม:** แต่ละสกิลบอกค่าหลัก โบนัสความแรง และจุดเปลี่ยนที่ได้แล้ว / ใบถัดไป
- **การ์ดจะไม่หมด:** เมื่อสกิลตันทุกตัว การ์ด 3 ใบเป็นค่าสถานะต่างกันเสมอ (ยา/ถุงทองยังโผล่ได้บ้าง)

## 5. งานที่ต้องทำ (เมื่ออนุมัติ)

- **ข้อมูล:** ใส่ `main` และ `ms` (จุดเปลี่ยน) ให้ 40 สกิล
- **สูตร:**
  - ปรับ `recalc` ให้รองรับใบที่ 6+ และเพดาน
  - ความแรงตามค่าหลักคูณใน damage ของสกิล (โหมดตัวละครเท่านั้น)
- **แตะ core:**
  - แตะ `damageEnemy` / `recalc` / ตัวสร้างกระสุนเล็กน้อย
  - ผูกไว้กับ `G.char` เพื่อให้คลาสสิกไม่เปลี่ยน
  - ตรวจด้วย golden 5 อาชีพ
- **หน้าอัปเกรดถาวร:** เพิ่มหัวข้อใหม่ แตะเซฟ → ต้องผ่าน tester
- **วัดสมดุลด้วยบอท:** เอาชีวิตรอด T0–T5 ทุกอาชีพ ก่อน/หลัง ดูว่าไม่ง่ายเกินไป
