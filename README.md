ทั้งเกมอยู่ในไฟล์เดียว เขียนด้วย Canvas 2D + JS ล้วน ไม่มีไลบรารีภายนอก (นอกจากฟอนต์ Google Fonts)

## ระบบไอเทม (M2)

- **ข้อมูล** `src/js/33-items-data.js` (`ITEMS` อุปกรณ์ 74 ชิ้น tier 1–4 + ของใช้/วัสดุ/สีย้อม · `RUNES` 10 แบบจากศัตรูโหมดเอาชีวิตรอด · `DROPS` · `SHOP`) ·
  **ตรรกะ** `34-items-logic.js` (กระเป๋า สวมใส่ ตีบวก รูน ดรอป ร้าน คลัง · pure ต่อตัวละคร) · **ของในสนาม** `35-loot-runtime.js` ·
  **หน้าจอ** `53-ui-char.js` · ตัวเลขทั้งหมดอยู่ใน `30-balance.js` (`BAL.REFINE` `BAL.PRICE` `BAL.DROP` `BAL.SURV`)
- **ตัวใหม่** ได้อาวุธฝึกหัดของอาชีพ (สวมอยู่) + ยาฟื้นพลังเล็ก ×3 ในช่องยาด่วน 1 + แต้มสกิลเริ่มต้น 6 (พอดัน "สกิลแรก" ถึง ★5) · ผู้เล่นเก่าที่มีสถิติคลาสสิกได้ผ้าคลุมผู้บุกเบิก
- **สวมใส่** 10 ช่อง · อาชีพ/เลเวลไม่ตรง = สวมไม่ได้ · ของที่สวมไม่นับในกระเป๋า (80 ช่อง ขยายได้ถึง 120) · ถอดตอนกระเป๋าเต็มไม่ได้ ·
  อาวุธที่สวมเห็นบนตัวละครทั้งในป้อมและในสนาม · +7 ขึ้นไปเรืองแสง (+10 แรงขึ้น)
- **ตีบวก** +1…+10 (เครื่องประดับตีไม่ได้) · โอกาส 100/…/80/65/50/38/26/15% · ล้มเหลว +5/+6 คงเดิม · +7…+10 ลด 1 (ยันต์ผนึกกันลด) ·
  "ความเพียร" +4% ต่อครั้งที่พลาดติดกัน สูงสุด +20% · วัสดุและค่าแรงเสียทุกครั้ง · ของไม่พังไม่หาย · สุ่มด้วย `crypto` และ**บันทึกผลก่อนเล่นแอนิเมชัน**
  (ปิดแอปกลางแอนิเมชันแล้วเปิดใหม่ก็เห็นผลเดิม) · ตี +8 ขึ้นไปต้องกดปุ่มค้าง 1 วิ
- **รูน** เศษ 4 ชิ้น + 300 ทอง = รูน 1 ชิ้น · ฝังฟรีในช่องที่กลุ่มตรงกัน · ถอดเสียค่าบริการ 100 × tier แล้วรูนกลับเข้ากระเป๋า
- **ทอง** ใช้ร่วมทั้งบัญชี · กระเป๋าเป็นของแต่ละตัว · คลังใช้ร่วม (60 ช่อง ขยายด้วยตราผู้พิชิต) · ของซ้อน: วัสดุ 999 · ยา 99 ต่อช่อง
- id ที่มาจากเซฟหรือ UI ต้องค้นด้วย `itemDef()` / `itHas()` (own-property) เสมอ ห้าม `ITEMS[id]` ตรง ๆ
- ของบนพื้น (`ITEMKIND.loot` / `.gold` / `.bosschest`) วาดจาก atlas เดียวที่วาดไว้ล่วงหน้า และ core วาดแสงของทุกชิ้นในรอบเดียว
  (วาดเวกเตอร์ทุกเฟรมเคยทำให้ช้าลง ~40% เมื่อมีของ 20 ชิ้นบนจอ) · M2 โหมดเอาชีวิตรอดไม่วางของบนพื้น (ของเข้า `G.loot` ตรง) มีแต่ dev hook

## build / ตรวจ / เล่นในเครื่อง

```
node build.mjs                    # ประกอบ src/ + ตรวจ L1–L11 + เขียน runeguard.html + dist
node build.mjs --lint             # ตรวจอย่างเดียว
node build.mjs --check            # fail ถ้า runeguard.html ไม่ตรงกับ src/ (ลืม build)
node build.mjs --verify-split=F   # เทียบ sha256 ผลประกอบกับไฟล์ F (ไม่เขียนอะไร)
npm test                          # node test/run.mjs (เทสต์ทุกไฟล์) + --check
```
แก้เกม = แก้ไฟล์ใน `src/` แล้วรัน `node build.mjs` ทุกครั้ง · แก้ core (`04–25`, `90`) ต้องรัน golden ใหม่ (`test/golden/README.md`)

### เทสต์

```
node test/run.mjs                 # รัน test/*.test.mjs ทุกไฟล์ทีละ process สรุปเป็นไทย · ไม่ผ่านแม้ไฟล์เดียว = exit 1
node test/run.mjs -v              # แสดงผลเต็มของทุกไฟล์
node test/run.mjs 30 names        # เฉพาะไฟล์ที่ชื่อมีคำเหล่านี้
node test/names.test.mjs          # ไฟล์เดียวก็รันตรง ๆ ได้
```
- ไม่มี dependency · เทสต์ของ lane รันไฟล์จริงใน `src/js` ผ่าน `node:vm` (`test/_vm.mjs`) พร้อม localStorage ในหน่วยความจำ
- lane เพิ่มเทสต์ได้โดยสร้าง `test/NN-name.test.mjs` ที่จบด้วย `process.exit(fail ? 1 : 0)` — `run.mjs` เจอเอง
- `names.test.mjs` รวม `n` จาก SK (+ `evo.n`), PASSIVES, ITEMS, RUNES, EN, MOBS, ZONES, BOSS_LIST และชื่ออาชีพ ชื่อซ้ำ = ไม่ผ่าน
- golden run ของคลาสสิก (ต้องตรงทุกตัวอักษร รวมถึงตอนเลือกตัวละครค้างไว้) รันในเบราว์เซอร์ตาม `test/golden/README.md`

### ทดสอบ M2 ในเบราว์เซอร์ (สรุป)
- **golden + ตัวละครติดเกียร์:** สร้างตัวละครที่สวมของหลายชิ้น ตีบวก +7 และฝังรูน (`RG.profile.give` / `RG.items.*`) ให้บันทึกแล้ว **reload** จากนั้นรัน golden 5 อาชีพ → ต้องตรงทุกตัวอักษร และเซฟไม่เปลี่ยน

- **ความเร็ว (§7.10):** เทียบ A/B ในหน้าเดียว (iframe ของ build เดิมกับ build ใหม่ origin เดียวกัน · หยุด rAF ของ iframe ก่อน · `RG.quality('high')` · ทุกรอบ `RG.seed(42)` แล้วจำลองถึงคลื่น 15 · สลับลำดับ ABBA · ใช้อัตราส่วน median) · คลาสสิก ±5% · เอาชีวิตรอดด้วยตัวติดเกียร์ + ของบนพื้น ≤ คลาสสิก +3%

## PWA ช่วยอะไร (และไม่ช่วยอะไร)

- **ช่วย:** ติดตั้งลงหน้าจอเหมือนแอป, เปิดเต็มจอไม่มีแถบเบราว์เซอร์, เปิดครั้งถัดไปทันทีจากแคช, เล่นออฟไลน์ได้, จอไม่ดับระหว่างเล่น (wake lock)
- **ไม่ได้เพิ่ม FPS เอง** — ความลื่นมาจากตัวเกม: sprite วาดล่วงหน้า, texture แสงเก็บแคช, ตัวเลขดาเมจจาก atlas, pool ของผล query, canvas แบบ `alpha:false`
  และ **คุณภาพกราฟิกอัตโนมัติ** (ลด/เพิ่มความละเอียดจอ จำนวนอนุภาค รอยบนพื้น ตามเวลาต่อเฟรม) — เลือกเองได้ในเมนูพักเกม
- อัปเดตเกม: เปิดครั้งแรกหลัง deploy ใหม่จะยังเห็นเวอร์ชันเก่าจากแคช เมื่อ service worker ตัวใหม่พร้อมจะขึ้นปุ่ม
  "อัปเดตพร้อม · แตะเพื่อโหลดใหม่" (หรือได้เวอร์ชันใหม่เองตอนเปิดครั้งถัดไป)

## deploy

- GitHub: push ขึ้น `main` · Vercel: ถ้าเชื่อม repo ไว้จะ deploy อัตโนมัติทุก push,
  หรือสั่งเองด้วย `npx vercel --prod` ในโฟลเดอร์นี้ (ต้อง `npx vercel login` ก่อน)

## Hook สำหรับทดสอบ (`#dev`)

เปิดด้วย `...#dev` จะมี `window.RG` ใน console (ไม่มี `#dev` = ไม่มี hook ผู้เล่นทั่วไปโกงคะแนนไม่ได้)

| คำสั่ง | ทำอะไร |
|---|---|
| `RG.start('mage')` | เริ่มเกม (`swordsman` `mage` `archer` `cleric` `thief`) |
| `RG.sim(60)` | เร่งเวลา 60 วินาทีด้วยบอท (ข้ามป้าย/เสียง/อนุภาค/รอยพื้น — ใช้วัดสมดุล ไม่ได้ทดสอบกราฟิก) |
| `RG.renderMs(40)` | รัน update+render จริง 40 เฟรม คืนค่ามิลลิวินาทีต่อเฟรม (ทดสอบกราฟิกจริง) |
| `RG.info()` / `RG.state()` | สรุปสถานะ / object เกมทั้งหมด (`RG.state().player` = ผู้เล่น) |
| `RG.god(true)` · `RG.ui()` · `RG.quality('low')` | อมตะ · เปิดหน้าเลเวลอัพ/เปลี่ยนอาชีพที่ค้าง · ตั้งคุณภาพกราฟิก |
| `RG.seed(42)` | ทำให้สุ่มซ้ำได้ (ใช้กับ golden run: `RG.seed(42); RG.start(c); RG.sim(600)`) |
| `RG.run(mode, opts)` | เริ่มโหมดอื่น (`MODES` ใน `src/js/25-mode-survival.js` และไฟล์ของแต่ละ lane) · lane เติม `DEV.<ns>` แล้วจะโผล่เป็น `RG.<ns>` · โหมดที่ใช้ตัวละครจะใช้ตัวที่เลือกอยู่ (`RG.run('survival', {tier: 0})`) · `RG.run('classic', {cls: 'mage'})` ไม่ใช้ตัวละคร |
| `RG.profile.sandbox(true)` | เซฟชั่วคราวในหน่วยความจำ ไม่เขียนลงเครื่องเลย (`'copy'` = สำเนาเซฟปัจจุบัน · `false` = กลับไปใช้เซฟในเครื่อง) |
| `RG.profile.char({cls, name, lv, jlv, job, st, sk, pas, load, trial})` | แก้/สร้างตัวละครที่เลือกอยู่ เช่น `RG.profile.char({cls:'mage', lv:20, jlv:20, sk:{mbolt:5, flame:3}})` |
| `RG.profile.get()` · `.json()` · `.state()` · `.reset()` · `.gold(n)` · `.exp(base, job)` · `.give(id, n, {r})` | อ่านเซฟ · เซฟเป็นข้อความ · สถานะการเก็บ · ล้างเซฟ (ไม่ทับเซฟจากเวอร์ชันใหม่กว่า) · ตั้งทอง · ให้ EXP · ให้ไอเทม (`{r: 7}` = อุปกรณ์ +7) |
| `RG.items.equip(uid)` · `.unequip(slot)` · `.refine(uid, seal)` · `.info(uid)` · `.socket(uid, rune, i)` · `.unsocket(uid, i)` · `.combine(shard)` · `.buy(id, n)` · `.sell(x, n)` · `.stash(x, toStash, n)` · `.bonus()` · `.look()` · `.bag()` | API ของ `34-items-logic.js` กับตัวละครที่เลือกอยู่ (ผลลงเซฟจริง) |
| `RG.refine.dist(tier, target, n)` | สุ่มตีบวก n ครั้ง (crypto) เทียบกับอัตราในตาราง → `{p, measured, diff}` |
| `RG.loot.roll(table, n)` · `.seed(n \| null)` · `.drop()` · `.gold(n)` · `.chest()` | ค่าเฉลี่ยของดรอปต่อครั้ง (เช่น `'surv.boss10'`) · ดรอปแบบ seed · วางของ/ทอง/กล่องบนพื้นข้างผู้เล่น |
| `RG.charui.tab('equip' \| 'bag')` · `.item(uid)` · `.refine(uid)` · `.scribe()` · `.shop()` · `.stash()` · `.state()` | เปิดหน้าตัวละคร / แผ่นงานไอเทม / ช่างตีเหล็ก / ผู้จารึกรูน / ร้าน / คลัง |
| `RG.commit = true` | ให้ `RG.sim` บันทึกรางวัลจบรอบลงเซฟจริง (ค่าเริ่มต้น: sim ไม่บันทึก) |
| `RG.ui()` · `RG.ui.go('scrSkills')` · `RG.ui.back()` · `RG.ui.home()` · `RG.ui.stack()` | `RG.ui()` แบบเดิม · ไปหน้าต่าง ๆ ของ v2 · ดู stack ของหน้า |
| `RG.prog.open('skills' \| 'job' \| 'stats')` | เปิดหน้าสกิล / อาชีพ / แท็บสถานะ |

## ปรับสมดุลตรงไหน (ค้นหาใน `src/js/`)

- `waveCfg(w)` อัตราเกิด/HP/ดาเมจศัตรู · `BOSS_WAVES` บอส · `bossAI()` ท่าบอส
- `const SK=` สกิลทั้ง 40 (array 5 ช่อง = Lv1–5, `evo.set` = ค่าหลังวิวัฒนาการ) · `const CLASSES=` อาชีพ · `const EN=` ศัตรู
- `xpNeed` EXP ต่อเลเวล · `ADV_LV` เลเวลเปลี่ยนอาชีพ · `CAP` ศัตรูพร้อมกันสูงสุด
- กราฟิก: `QDPR` `QPART` `QDECAL` `QCORPSE` `QSS` = ค่าต่อระดับคุณภาพ (ต่ำ/กลาง/สูง)
